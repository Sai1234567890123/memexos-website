Quickstart Guide

Welcome to the MemexOS developer documentation. MemexOS is a universal AI memory layer that turns your unstructured data into a real-time, queryable knowledge graph powered by Claude.

Note: You must have a valid API key to use the remote backend. If no key is provided, the SDK will run in local mock mode.

Installation

Install the official MemexOS Node.js SDK via NPM:

npm install memexos

Initialization

Import the MemexClient and initialize it with your API key. By default, it will look for the MEMEXOS_API_KEY environment variable.

const { MemexClient } = require('memexos'); const memex = new MemexClient({ apiKey: process.env.MEMEXOS_API_KEY });

Ingesting Memory

The core of MemexOS is mapping unstructured data. You can pipe raw text from Notion, browser logs, or chat applications directly into the addMemory endpoint.

await memex.addMemory("I had a meeting with John today about the new Claude integration.", { source: "notion", tags: ["meeting", "AI"] });

Querying the Graph

Once your data is ingested, MemexOS orchestrates Claude 3.5 Sonnet to perform multi-hop RAG across your entire memory graph.

const response = await memex.query("What was my meeting about today?"); console.log(response.answer); // Output: "Synthesized response based on 1 memory node(s)..."
